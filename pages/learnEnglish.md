# Do vs. Does — Quick Reference

## Core Rule
- Use **does** only with **third-person singular** subjects in the simple present.
- Use **do** with **all other subjects** (I, you, we, they, and all plurals).

> Third-person singular = he, she, it, or any single thing/person treated as “it”  
> (e.g., this script, the app, my friend, everyone, nobody).

---

## Subject → Verb Form

| Subject type                 | Example subjects                     | Verb form |
|-----------------------------|--------------------------------------|-----------|
| First person singular       | I                                    | do        |
| Second person               | you (singular or plural)             | do        |
| First person plural         | we                                   | do        |
| Third person plural         | they, the users, these scripts       | do        |
| **Third person singular**   | he, she, it, this script, the app    | **does**  |

---

## Examples

### Affirmative
- I **do** the updates every Monday.  
- You **do** great work.  
- We **do** testing before release.  
- They **do** the deployment at night.  
- He **does** the review.  
- She **does** the planning.  
- It **does** what it’s supposed to.  
- This script **does** exactly what the name suggests.

### Negative (do/does + not)
- I **do not** (don’t) know.  
- You **do not** (don’t) need to worry.  
- We **do not** (don’t) run it on Fridays.  
- They **do not** (don’t) use that feature.  
- He **does not** (doesn’t) agree.  
- She **does not** (doesn’t) like bugs.  
- It **does not** (doesn’t) work on Windows.  
- This script **does not** (doesn’t) modify files.

### Questions
- **Do** I need to restart?  
- **Do** you see the error?  
- **Do** we have tests for this?  
- **Do** they support Linux?  
- **Does** he know about the change?  
- **Does** she handle the logs?  
- **Does** it timeout after 30s?  
- **Does** this script delete anything?

## Precautions & Common Traps

1. **Don’t match the verb to the object.**  
   - Correct: This script **does** many things.  
   - Wrong: This script **do** many things.  
   (Verb agrees with “this script”, not “many things”.)

2. **Collective nouns and quantifiers often act as third-person singular.**  
   Use **does** with:  
   - everyone / everybody  
   - someone / somebody  
   - no one / nobody  
   - each student / each user  
   - the team / the company (when treated as one unit)  
   Example: Everyone **does** their part. The team **does** daily standups.

3. **Compound subjects joined by “and” are plural → use do.**  
   - The script and the config **do** different things.  
   - He and she **do** the review together.

4. **“You” is always do, even for one person.**  
   - You **do** the setup. (one person or many)

5. **In questions and negatives, the auxiliary still follows the same rule.**  
   - **Does** this command work?  
   - This command **does not** work.  
   - **Do** these commands work?  
   - These commands **do not** work.

6. **Only simple present uses do/does this way.**  
   Past tense uses **did** for all persons:  
   - I/you/he/they **did** the test yesterday.

---

## One-Sentence Summary
> Use **does** only when the subject is third-person singular; otherwise, use **do**.
