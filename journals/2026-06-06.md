- #### Use "appman"
    - `appman search rustdesk` # Search a package
        - `search` # Replace it with `install` (`remove`) to install (remove)
    - `appman files` # List installed apps
- ***Notes***
    - `appman --relocate` # Remove and reinstall apps in another location (e.g. `.local/appman`)
    - Because I want to manage AppImage using a single command.
    - `wget -q https://raw.githubusercontent.com/ivan-hc/AM/main/AM-INSTALLER && chmod a+x ./AM-INSTALLER && ./AM-INSTALLER && rm ./AM-INSTALLER` # Install depeendencies
        - `rm ~/.local/bin/appman` # Uninstall dependencies
