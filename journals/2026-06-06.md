- #### Use "appman"
    - `appman search rustdesk` # Search a package
        - `install` # Replace `search` with it to install
- ***Notes***
    - Because I want to manage AppImage using a single command.
    - Install
      ```
      wget -q https://raw.githubusercontent.com/ivan-hc/AM/main/AM-INSTALLER && chmod a+x ./AM-INSTALLER && ./AM-INSTALLER && rm ./AM-INSTALLER
      ```
    - Uninstall
      ```
      rm ~/.local/bin/appman
      ```
