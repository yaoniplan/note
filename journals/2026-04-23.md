- #### Use "z"
    - `z ~/.config/niri/` # The same as `cd ~/.config/niri/`
        - `z niri` # cd into directory (highest ranked) matching niri
        - `zi` # Interact using fzf (View the cd history)
- ***Notes***
    - `nix profile install nixpkgs#zoxide` # Install dependencies
    - `vim ~/.bashrc` # Set up for Bash
      ```
      ## Replace the `cd` command (The same as `alias cd=z`)
      #eval "$(zoxide init --cmd cd bash)"
      eval "$(zoxide init bash)"
      ```
        - `source ~/.bashrc` # Make changes effective
    - `vim ~/.profile` # Setup up for `/bin/sh` (e.g. Alpine Linux)
      ```
      eval "$(zoxide init posix)"
      ```
        - `--hook prompt` # Sovle the problem
          ```
          [~]# source ~/.profile
          zoxide: PWD hooks are not supported on POSIX shells.
                  Use 'zoxide init posix --hook prompt' instead.
          [~]#
          ```
        - `--cmd cd` # Replace the default `cd`
    - Because to experience a smarter cd command.
