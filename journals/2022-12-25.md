- #### Use "ln"
    - `ln --symbolic ~/Documents/.config/yt-dlp ~/Library/Preferences/yt-dlp` # Link a folder to another folder
      ```
      # Create a relative symbolic link (Avoid invalidation after updates)
      python3 -c 'import os; l=os.path.expanduser("~/Library/Preferences/yt-dlp"); t=os.path.expanduser("~/Documents/.config/yt-dlp"); os.path.lexists(l) and os.unlink(l); os.symlink(os.path.relpath(t,os.path.dirname(l)),l); print(os.readlink(l))'
      ```
    - `ln --symbolic ~/.config/i3/config ./i3/config` # Link a file to another file
        - `ln` # Link
- ***Notes***
	- `unlink ./i3/config` # Remove a symbolic link
        - Warning: this `unlink` command is dangerous, not recommended. (Otherwise normal files may be accidentally deleted.)
    - `~/.config/i3/config` # A hard link
    - `./i3/config` # A symbolic link
        - `mkdir ./i3/` # Make a directory before using the *ln* command
    - Optional: Check the symbolic link and the hard link
        - `ls -l ./i3/config`
    - Because to make a symbolic link on Linux.
