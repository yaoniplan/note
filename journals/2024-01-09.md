- #### Use "fzf"
    - `echo -e "1\n2\n3" | fzf`
- ***Notes***
    - `--pointer='➤'` # Replace the default pointer '▌' to the current line with '➤'
    - `--sync --bind 'start:pos(10)'` # Put the cursor on the 10th item
        - https://github.com/junegunn/fzf/blob/838ac7554bdbae2f457f2c4969e1b38f1c28c946/CHANGELOG.md?plain=1#L1845
    - `Ctrl-j/k` # Next/previous selection (Same as `Ctrl-n/p`)
    - `Ctrl-m` # Enter key
    - `--prompt 'Search: '` # Replace the default input prompt '> ' with it
    - `--reverse` # Put the search bar in the top of screen
    - `--tac` # Arrange the input lines in reverse order
    - `vi ~/.bashrc` # Bind `Ctrl-j` key to `Enter` key (Like Bash)
      ```
      export FZF_DEFAULT_OPTS="--bind=ctrl-j:accept"
      ```
        - `source ~/.bashrc` # Make changes effective
    - Because to try using a more general launcher on multiple platforms (And use the fastest launching terminal as the window)
