- #### Use "jq"
    - Construct JSON data from scratch
      ```
      jq --null-input \
        --arg title "乱世书" \
        --argjson current_index 0 \
        --rawfile urls luanshishu.txt '
      {
        title: $title,
        current_index: $current_index,
        url: [$urls | split("\n")[] | select(. != "")]
      }
      ' > luanshishu.json
      ```
        - `jq --raw-output '.url[.current_index : .current_index + 3][]' luanshishu.json` # Get next 3 URLs from an array
        - `jq --raw-output '.url[.current_index - 1]' luanshishu.json` # Get current URL from an array
        - `jq '.current_index = 2' luanshishu.json > luanshishu.json` # Update the current index (absolute)
        - `jq '.current_index += 3' luanshishu.json  > luanshishu.json` # Update the current index (relative)
        - `jq --rawfile new_urls luanshishu.txt '.url = ($new_urls | split("\n") | map(select(length > 0)))' luanshishu.json > luanshishu.json.tmp && mv luanshishu.json.tmp luanshishu.json` # Update an array
        - `jq '.url | length' launshishu.json` # Count the number of elements in an array

- ***Notes***
    - `--join-output` # Removes the trailing newline (As an input parameter for the next operation)
    - `[.[] | {(.timestamp): .message}]` # Output matches your required format
    - `.[].url`
        - `.[]` # Iterate over each object
    - `.data.content[] | select(.is_dir == false) | "\(.name | @uri)?sign=\(.sign)"`
        - `select(.is_dir == false)` # Filter items where `is_dir` is `false`
        - `"\()"` # Embed the value of a field or expression inside a string
        - `@uri` # Uniform resource identifier (Encode a string)
    - `.data.content[].name` # Navigate to the `name` field within each object in the `content` array inside the `data` object, extract each `name` value
        - `.data` # Access the `data` key in the JSON object
        - `.content` # Access the `content` array
        - `[]` # Iterate over each element of the `content` array
        - `.name` # Access the `name` field of each object in the `content` array
