- #### Use "uv"
    - Build a Python project
        - `uv init` # Create a new Python project in the current directory
        - `uv add selenium` # Add a selenium package to the project (Opposite: `remove`)
        - `uv tree` # Display the project's dependency tree
        - `uv run checkIn.py` # Run a script in the project's environment
        - `uv tool install --editable .` # Install globally in development mode (Update by modifying the source code)
          ```
          # Solve the problem about
          # 'No executables are provided by package `ani`; removing tool'
          # pyproject.toml
          [project.scripts]
          ani = "main:main"
          ```
        - `vim ~/.local/bin/ani` # Add to the executable environment if the above method sometimes does not work
          ```
          #!/usr/bin/env sh
          exec uv run --directory ~/.local/src/ani main.py
          ```
    - `uv pip install anki` # Replace `install` with `uninstall` to uninstall it
        - `uv pip list` # List installed packages
    - Install Python tools globally (The ImportError problem makes it impossible to use)
        - `uv tool install xklb` # Replace `install` with `uninstall` to uninstall
        - `uv tool install git+https://github.com/grqz/yt-dlp.git@ie/bilibili/pi_fallbk` # From package source (Install patched software)
        - `uv tool install git+https://github.com/yt-dlp/yt-dlp.git@refs/pull/12048/head` # Install the specific commit from the PR
        - `uv tool list` # List installed tools (`--outdated`)
        - `uv tool upgrade yt-dlp` # Upgrade the tool
    - Call script from anywhere
        - Warning: it's not portable when some devices (e.g. iPhone) can't install `uv` command (Not recommended)
        - `uv add --script ~/.local/bin/chinese-to-pinyin.py pypinyin` # Add the dependency to the specified Python script
        - `vim ~/.local/bin/chinese-to-pinyin.py` # Update the shebang to use `uv run --script` to execute this script
          ```
          #!/usr/bin/env -S uv run --script
          ##!/usr/bin/env python
          ```
