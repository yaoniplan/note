- #### Use "awww"
    - `awww query` # Query information
    - `awww img /usr/share/hypr/wall_anime_2K.png` # Use this image as wallpaper
        - `awww-daemon` # Run in the background as a daemon at boot time
- ***Notes***
    - `--transition-type any` # Fashion
    - `nix profile install nixpkgs#awww` # Install dependencies
    - Because to set wallpaper on Wayland.

    - https://codeberg.org/LGFae/awww#usage
    - https://wiki.hyprland.org/Useful-Utilities/Wallpapers/
