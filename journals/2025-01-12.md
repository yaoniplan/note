- #### Use "yazi"
    - `yazi`
        - `; chromium %h` # Open the hovered file (e.g. index.html) in a browser
        - `;` # Run a shell command using `sh`
        - `G` # Move cursor to the bottom (Opposite: `g g`)
        - `Tab` # View file times (created/modified)
        - `J` # Scroll down in the preview (Opposite: `K`)
        - `S` # Search file contents in the current directory and subdirectories using `rg`
        - `.` # Show or hide dotfiles
        - `q` # Quit
        - `~` # Open the help menu
        - `g <Space>` # Go to the path you want to go
        - `g h` # Go home
        - `Z` # Jump to a directory via zoxide
        - `c c` # Copy file path (The same as `realpath`)
        - `, r` # Sort randomly
- ***Notes***
    - `ya pkg add grappas/wl-clipboard` # Install this plugin if clipboard doesn't work
        - `add` # Replace it with `delete` to delete
        - `ya pkg list` # List all packages (e.g. `yazi-rs/flavors:catppuccin-mocha`)
        - `ya pkg add GianniBYoung/rsync` # Use rsync (Remember to add https://github.com/GianniBYoung/rsync.yazi#remember-last-target bind)
        - `ya pkg add AnirudhG07/custom-shell` # Use default shell (Remember to add https://github.com/AnirudhG07/custom-shell.yazi#recommended-keybindings bind)
    - `vim ~/.config/yazi/theme.toml` # Configure themes
      ```
      [flavor]
      dark = "catppuccin-mocha"
      #light = "catppuccin-latte"
      ```
    - `vim ~/.config/yazi/keymap.toml` # Configure keybindings
      ```
      [[mgr.prepend_keymap]]
      on   = [ "g", "b" ]
      run  = "cd ~/.local/bin"
      desc = "Goto ~/.local/bin"

      [[mgr.prepend_keymap]]
      on   = [ "<C-j>" ]
      run  = "open"
      desc = "Open file or enter directory"
      ```
    - `v` # Visial mode (Selection mode, select multiple and delete in batches)
    - `<Space>` # Select current item (Toggle)
    - Delete a directory
        - `/tachi` # Search for the directory you want to delete
        - `d` # Delete (Move it to `~/.local/share/Trash/`)
        - `y` # Yes
        - `g t` # Go to trash bin
        - If it keeps showing loading, just delete the orphaned files in these two folders (`./files` and `./info`)
        - `Shift-o` # Open selected files interactively (e.g. Restore selected files)
        - `D` # Delete files permanently
    - Because to use the fastest file manager.
    - `nix profile add nixpkgs#yazi` # Install dependencies
