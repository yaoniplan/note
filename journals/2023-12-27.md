- #### Use "aria2c"
    - `touch ~/.config/aria2c/aria2.session`
    - `vim ~/.config/aria2c/aria2.conf`
      ```
      dir = /home/yaoniplan/.config/aria2c
      enable-rpc = true
      rpc-allow-origin-all = true
      rpc-listen-all = true
      continue = true
      input-file = /home/yaoniplan/.config/aria2c/aria2.session
      save-session = /home/yaoniplan/.config/aria2c/aria2.session
      max-concurrent-downloads = 5
      ```
    - `aria2c --conf-path ~/.config/aria2c/aria2.conf`
- ***Notes***
    - Because we need to reduce the download time for a file that is downloading very slowly.
    - `aria2c -x4 -s4 -k1M 'https://example.com/sample.mp3'` # Download in parallel with multiple threads

        - `-s` # `--split=`
        - `-k` # `--min-split-size=`
